## 네트워크 연결

네트워크는 연결하는 범위(규모)에 따라 LAN, MAN, WAN으로 구분함

| 구분 | 범위 | 예시 | 구축 주체 |
| --- | --- | --- | --- |
| LAN | 건물, 층, 집 | 가정, 사무실 네트워크 | 사용자가 직접 구축 |
| MAN | 도시 | 지자체, 대학 캠퍼스 간 네트워크 | 자체 구축 또는 통신사업자 |
| WAN | 국가, 대륙 | 본사-지사 연결, 인터넷 | 통신사업자 회선 임대 |

### LAN(Local Area Network)

- 사용자 내부 네트워크
- 홈 네트워크나 사무실 네트워크처럼 비교적 가까운 거리, 소규모의 네트워크를 말함
- 사용자가 직접 장비를 구매해 구축하고 관리함
- 거리가 짧아 전송 속도가 빠르고 에러 발생률이 낮음
- 대부분 **이더넷** 기술을 사용하며, 무선 LAN은 **Wi-Fi**(IEEE 802.11)를 사용함

### MAN(Metropolitan Area Network)

- 한 도시 정도의 범위를 연결하고 관리하는 네트워크
- LAN보다는 넓고 WAN보다는 좁은 범위
- 일반적으로 도시 단위의 네트워크를 구분할 때는 통신사업자가 이미 갖고 있는 인프라를 기반으로 네트워크를 구축하면 WAN, 자체 인프라를 통해 네트워크를 구축하면 MAN으로 구분하기도 함

### WAN(Wide Area Network)

- 멀리 떨어진 LAN을 연결해주는 네트워크
- WAN은 특별한 경우가 아니면 직접 구축할 수 없는 범위의 네트워크이므로 대부분 통신사업자로부터 회선을 임대해 사용함
- LAN에 비해 전송 거리가 길어 속도가 느리고 비용이 비쌈
- WAN 연결 방식은 크게 **인터넷 회선, 전용 회선, 인터넷 전용 회선, VPN**으로 나눌 수 있음

**인터넷 회선**

- 인터넷 접속을 위해 통신사업자와 연결하는 회선
- 통신사업자가 판매하는 인터넷과 연결된 회선을 사용해야만 인터넷 접속이 가능함
- 예) 아파트에서 통신사업자까지 연결한 회선을 아파트 가입자들이 공유하는 구조
  - 전송 선로를 공유하므로 일반 인터넷 회선의 속도는 **전송 가능한 최대 속도**일 뿐이고, 그 속도를 보장하지 않음 (주변 사용량에 따라 속도가 느려질 수 있음)
- 가격이 저렴해 가정이나 소규모 사무실에서 주로 사용함

**전용 회선**

- 가입자와 통신사업자 간에 **대역폭을 보장**해주는 서비스를 대부분 전용 회선이라고 부름
- 대역폭을 보장해주는 기술에는 여러 가지가 있지만, 가입자와 통신사업자 간에는 전용 케이블로 연결되어 있고 통신사업자 내부에서 **TDM(Time Division Multiplexing, 시분할 다중화)** 같은 기술로 마치 직접 연결한 것처럼 통신 품질을 보장해줌
  - TDM : 하나의 회선을 시간 단위로 잘게 나눠 각 가입자에게 고정된 시간(타임 슬롯)을 할당하는 방식. 다른 가입자가 사용량이 많아도 내게 할당된 슬롯은 영향을 받지 않음
- 본사와 지사를 직접 연결하는 등 **특정 지점 간(Point-to-Point)** 연결에 사용됨
- 품질은 좋지만 거리와 대역폭에 따라 비용이 비쌈

**인터넷 전용 회선**

- 인터넷 연결 회선에 대한 통신 대역폭을 보장해주는 상품
- 가입자가 통신사업자와 연결되고 이 연결이 다시 인터넷과 연결되는 구조
- 일반 가정에서 사용하는 접속 기술과 달리 다른 가입자와 경쟁하지 않고 통신사업자와 가입자 간의 연결 품질을 보장해줌
- 안정적인 서비스가 필요한 기업이나 IDC(데이터 센터)에서 주로 사용함

| 구분 | 인터넷 회선 | 전용 회선 | 인터넷 전용 회선 |
| --- | --- | --- | --- |
| 연결 대상 | 인터넷 | 특정 지점 간 | 인터넷 |
| 대역폭 보장 | X (최대 속도) | O | O |
| 비용 | 저렴 | 비쌈 | 비쌈 |

### VPN(Virtual Private Network)

- 물리적으로는 전용선이 아니지만 **가상으로 직접 연결한 것 같은 효과**가 나도록 만들어주는 네트워크 기술
- 하나의 물리적인 네트워크를 여러 가입자가 공유하지만, 각 가입자의 트래픽을 논리적으로 분리하거나 암호화해서 전용선처럼 사용할 수 있게 함

**통신사업자 VPN**

- 전용선은 사용 가능한 대역폭을 보장해주지만, 가입자가 계약된 대역폭을 항상 100% 사용하는 것이 아니어서 낭비되는 비용이 클 수 있음
- 이런 비용 낭비를 줄이고 먼 거리와 연결하더라도 비용을 줄이기 위해 통신사업자가 직접 가입자들을 구분할 수 있는 VPN 기술을 사용해 비용을 낮춤
- 대표 기술 : **MPLS VPN**
  - 통신사업자 망 안에서 가입자별로 라벨을 붙여 트래픽을 구분함
  - 통신사업자가 망을 관리하므로 가입자는 별도의 VPN 장비나 설정이 필요 없음

**가입자 VPN**

- 일반 사용자가 VPN을 사용한다면 대부분 가입자 VPN 기술
- 일반 인터넷망을 이용해 사용자가 직접 전용 네트워크를 구성할 수 있음
- 공용망인 인터넷을 지나가므로 **터널링과 암호화**로 데이터를 보호함
- 대표 기술
  - **IPSec VPN** : 3계층에서 동작. 본사-지사처럼 네트워크와 네트워크를 연결(Site-to-Site)할 때 주로 사용
  - **SSL VPN** : 웹 브라우저나 전용 클라이언트로 접속. 재택근무자처럼 개인이 회사 네트워크에 접속(Remote Access)할 때 주로 사용

### DWDM(Dense Wavelength Division Multiplexing, 고밀도 파장 분할 다중화)

- **WDM(파장 분할 다중화)** : 하나의 광케이블에 서로 다른 파장(색)의 빛을 실어 여러 채널을 만들어 동시에 많은 데이터를 전송하는 기술
  - 프리즘으로 빛이 여러 색으로 나뉘는 것처럼, 파장이 다른 빛은 서로 간섭하지 않는 원리를 이용함
- WDM은 파장 간격에 따라 두 가지로 나뉨
  - **CWDM(Coarse WDM)** : 파장 간격이 넓어 채널 수가 적지만(최대 18채널) 장비가 저렴함. 비교적 짧은 거리에 사용
  - **DWDM(Dense WDM)** : 파장 간격을 촘촘하게 나눠 수십~수백 개의 채널을 만들 수 있음. 장거리, 대용량 전송에 사용
- 광케이블을 새로 포설하지 않고도 기존 케이블 하나로 전송 용량을 크게 늘릴 수 있어 통신사업자 백본망이나 데이터 센터 간 연결에 주로 사용됨

## 네트워크 구성 요소

| 장비 | 동작 계층 | 기준 정보 | 역할 |
| --- | --- | --- | --- |
| 허브, 리피터 | 1계층 | 전기 신호 | 신호 재생성, 모든 포트로 전달 |
| 스위치 | 2계층 | MAC 주소 | 목적지 포트로만 전달 |
| 라우터 | 3계층 | IP 주소 | 네트워크 간 최적 경로로 전달 |
| 로드 밸런서 | 4계층(L4) / 7계층(L7) | 포트 번호, IP 주소 (L7은 URL 등) | 부하 분산 |
| 방화벽 | 4계층 | IP 주소, 포트 번호 | 정책 기반 허용/차단 |

### 네트워크 인터페이스 카드(NIC)

- 컴퓨터를 네트워크에 연결하기 위한 하드웨어 장치 (랜카드, 네트워크 어댑터라고도 부름)
- 1계층과 2계층에서 동작하며, 고유한 MAC 주소를 가짐
- 역할
  - 직렬화 : 컴퓨터 내부의 데이터를 케이블로 보낼 수 있는 전기 신호로 변환하고, 케이블로 들어온 전기 신호를 데이터로 변환함
  - MAC 주소 확인 : 받은 패킷의 도착지 주소가 자신의 MAC 주소가 아니면 폐기하고, 자신의 주소가 맞으면 시스템 내부에서 처리할 수 있도록 전달
  - 흐름 제어 : 패킷 기반 네트워크에서는 다양한 통신이 하나의 채널을 이용하므로, 이미 통신 중인 데이터를 처리하느라 새로운 데이터를 받지 못할 수 있음
    - 이로 인한 데이터 유실을 방지하기 위해 데이터를 받을 수 없을 때는 상대방에게 **통신 중지를 요청**할 수 있음 (PAUSE 프레임, IEEE 802.3x)

### 케이블과 커넥터

**이더넷 네트워크 표준**

이더넷 표준 이름은 `속도` + `전송 방식` + `케이블 종류(또는 전송 거리)`로 구성됨

```text
1000 BASE - T
 │     │    └─ 케이블 타입 : T(Twisted Pair), S(Short wavelength), L(Long wavelength) 등
 │     └────── 전송 방식 : 베이스밴드(Baseband). 디지털 신호를 변조하지 않고 그대로 전송
 └──────────── 속도 : 1000Mbit/s (10G는 10Gbit/s)
```

대표 표준

| 표준 | 속도 | 케이블 | 최대 거리 |
| --- | --- | --- | --- |
| 1000BASE-T / 10GBASE-T | 1Gbps / 10Gbps | 트위스티드 페어 (UTP) | 100m |
| 1000BASE-SX / 10GBASE-SR | 1Gbps / 10Gbps | 멀티모드 광케이블 | 수백 m (짧은 거리) |
| 1000BASE-LX / 10GBASE-LR | 1Gbps / 10Gbps | 싱글모드 광케이블 | 약 10km (긴 거리) |

**케이블**

- **트위스티드 페어 케이블(Twisted Pair)**
  - 두 가닥의 구리선을 꼬아 만든 케이블로, 일반적으로 랜선이라고 부르는 케이블
  - 선을 꼬아서 외부 전자기 간섭(노이즈)과 선끼리의 간섭(크로스토크)을 줄임
  - 피복 안 차폐(Shield) 여부에 따라 구분함
    - UTP(Unshielded) : 차폐 없음. 저렴해서 가장 많이 사용됨
    - FTP(Foiled) : 전체를 호일로 감쌈
    - STP(Shielded) : 각 쌍을 차폐해 간섭에 가장 강함
  - 카테고리(Cat)에 따라 지원 속도가 다름 (Cat.5e : 1Gbps, Cat.6 : 1Gbps~10Gbps(55m), Cat.6A : 10Gbps)
- **동축 케이블(Coaxial)**
  - 케이블 TV와 연결할 때 사용하는 두꺼운 검정 케이블
  - 중심 도체를 절연체와 외부 도체가 감싸고 있는 구조로 간섭에 강함
  - 초기 이더넷(10BASE5, 10BASE2)에서 사용했지만 현재 LAN에서는 거의 사용하지 않음
- **광케이블(Optical Fiber)**
  - 전기 신호 대신 **빛**으로 데이터를 전송함
  - 구리 케이블보다 신뢰도가 높고 더 먼 거리까지 통신할 수 있어, 높은 대역폭을 요구하거나 먼 거리를 통신해야 하는 네트워크 장비 간의 통신에 주로 사용됨
  - 신호 감쇄가 적고 주위 자기장의 간섭으로부터 비교적 자유로움

| 구분 | 싱글모드(SMF) | 멀티모드(MMF) |
| --- | --- | --- |
| 코어 굵기 | 매우 가늘다 (약 9㎛) | 비교적 굵다 (50, 62.5㎛) |
| 광원 | 레이저 | LED (또는 저가 레이저) |
| 전송 방식 | 하나의 빛(모드)이 가느다란 전송로를 직진 | 여러 경로(모드)의 빛이 반사되며 전송 |
| 전송 거리 | 수~수십 km | 수백 m |
| 비용 | 비쌈 | 저렴 |

> 멀티모드는 여러 빛이 서로 다른 경로로 반사되며 이동하기 때문에 도착 시간이 조금씩 달라지는 **모드 분산**이 발생해 거리가 길어질수록 신호가 왜곡됨. 그래서 먼 거리는 싱글모드를 사용함
{: .prompt-tip }

**커넥터**

- 케이블의 끝부분으로 네트워크 장비나 네트워크 카드에 연결되는 부분
- 대표 커넥터
  - RJ-45 : 트위스티드 페어 케이블에 사용하는 8핀 커넥터 (랜선 끝 모양)
  - LC : 광케이블용 소형 커넥터. 포트 밀도가 높아 현재 가장 많이 사용됨
  - SC : 광케이블용 사각형 커넥터. LC보다 크기가 큼

**트랜시버**

- 다양한 외부 신호를 컴퓨터 내부의 전기 신호로 바꿈 (예: 광 신호 ↔ 전기 신호)
- 네트워크 장비의 포트에 꽂아 사용하는 모듈 형태로, 필요한 케이블 종류와 거리에 맞게 교체할 수 있음
- 대표 규격
  - GBIC : 초기 1Gbps 트랜시버. 크기가 커서 현재는 거의 사용하지 않음
  - SFP : 1Gbps. GBIC보다 작은 소형 트랜시버
  - SFP+ : 10Gbps
  - QSFP+ / QSFP28 : 40Gbps / 100Gbps

### 허브

- 거리가 멀어질수록 약해지는 전기 신호를 재생성해주고, HUB라는 용어 그대로 여러 대의 장비를 연결할 목적으로 사용됨
- 1계층 장비로 MAC 주소를 이해하지 못함
- 단순히 들어온 신호를 모든 포트로 내보내 네트워크에 접속된 모든 단말이 경쟁하게 되므로 전체 네트워크 성능이 떨어짐
  - 허브에 연결된 모든 단말이 **하나의 충돌 도메인**에 속함
  - 송신과 수신을 동시에 할 수 없는 **반이중(Half Duplex)** 방식으로 동작함
- 패킷이 무한 순환해 네트워크 전체를 마비시키는 **루프**와 같은 다양한 장애의 원인이 되어, 현재는 거의 사용되지 않음

### 스위치

- 허브와 달리 MAC 주소를 이해할 수 있어 목적지 MAC 주소의 위치를 파악하고 목적지가 연결된 포트로만 전기 신호를 보냄
  - 포트별로 충돌 도메인이 분리되므로 단말끼리 경쟁하지 않음
- 허브는 무전기처럼 송수신을 동시에 할 수 없고 한쪽 방향으로만 동작(반이중)하지만, 스위치는 전화기처럼 송수신을 동시에 할 수 있음(**전이중, Full Duplex**)
- 이더넷 네트워크가 성능 보장이 가능한 효율 높은 네트워크 기술로 발전할 수 있었던 계기가 됨
- **VLAN(Virtual LAN)** 기능으로 하나의 물리 스위치를 여러 개의 논리적인 네트워크로 나눠 브로드캐스트 도메인을 분리할 수 있음
- 루프를 방지하기 위해 **STP**(Spanning Tree Protocol)를 사용함

### 라우터

- 3계층 장비로, IP 주소를 기반으로 **서로 다른 네트워크를 연결**함
- 정확한 방향으로 패킷이 전송되도록 경로를 지정하고 최적의 경로로 패킷을 포워딩함
  - 라우팅 테이블에 목적지 네트워크별로 어느 쪽으로 보내야 하는지 기록해 둠
  - 라우팅 테이블은 관리자가 직접 입력(정적 라우팅)하거나, 라우터끼리 정보를 교환해 자동으로 만들 수 있음(동적 라우팅 : OSPF, BGP 등)
- 원격지로 쓸데없는 패킷이 전송되지 않도록 브로드캐스트와 멀티캐스트를 컨트롤하고, 목적지를 알 수 없는 주소로 통신을 시도할 경우 이를 버림
  - 브로드캐스트를 다른 네트워크로 전달하지 않으므로 **브로드캐스트 도메인을 분리**함

### 로드 밸런서

- 여러 대의 서버에 트래픽을 나눠 보내 **부하를 분산**하는 장비
- 사용자는 로드 밸런서의 대표 IP(VIP)로 접속하고, 로드 밸런서가 실제 서버의 IP 주소로 변경해 전달함
  - 4계층 포트 주소를 확인하는 동시에 IP 주소를 변경할 수 있음
- 동작 계층에 따라 구분
  - **L4 로드 밸런서** : IP 주소와 포트 번호를 기준으로 분산
  - **L7 로드 밸런서** : URL, HTTP 헤더, 쿠키 등 애플리케이션 계층의 정보까지 확인해 분산
- 서버 상태를 주기적으로 확인(**헬스 체크**)해 장애가 난 서버에는 트래픽을 보내지 않음
- 대표 분산 방식 : 라운드 로빈, 최소 접속(Least Connection), 해시 등

## 보안 장비

- 네트워크 장비와 달리 정보를 잘 제어하고 공격을 방어하는 데 초점이 맞춰져 있음

**방화벽(Firewall)**

- OSI 7계층 중 4계층에서 동작해, 방화벽을 통과하는 패킷의 3, 4계층 정보(출발지·목적지 IP 주소, 포트 번호, 프로토콜)를 확인하고 정책과 비교해 버리거나 포워딩함
- 현대 방화벽은 **세션(상태) 기반**(Stateful Inspection)으로 동작함
  - 나가는 패킷의 세션 정보를 기록해 두었다가, 그 세션에 대한 응답 패킷은 별도 정책 없이 자동으로 허용함

**IDS / IPS(침입 탐지 / 침입 방지 시스템)**

- 방화벽이 확인하지 않는 **패킷의 내용**(페이로드)까지 검사해 공격 패턴을 찾아냄
- IDS(Intrusion Detection System) : 공격을 탐지하고 알림만 보냄
- IPS(Intrusion Prevention System) : 공격을 탐지하면 즉시 차단함

**WAF(Web Application Firewall)**

- 웹 서비스에 특화된 방화벽으로, 7계층(HTTP)에서 동작함
- SQL 인젝션, XSS 같은 웹 애플리케이션 공격을 탐지하고 차단함

**UTM / NGFW**

- UTM(Unified Threat Management) : 방화벽, IPS, VPN, 안티바이러스 등 여러 보안 기능을 하나의 장비로 통합한 장비
- NGFW(Next Generation Firewall) : 포트 번호가 아닌 **애플리케이션 단위**로 트래픽을 식별하고 제어할 수 있는 차세대 방화벽

## 모뎀 / 공유기

**모뎀(MODEM, MOdulator-DEModulator)**

- 짧은 거리를 통신하는 기술(이더넷)과 먼 거리를 통신하는 기술이 달라, 이 기술들을 서로 변환해 주는 장비
- 디지털 신호를 전송 매체에 맞는 아날로그 신호로 바꾸고(변조, Modulation), 다시 디지털 신호로 되돌림(복조, Demodulation)
- 연결 방식에 따라 다양한 모뎀이 있음
  - 케이블 모뎀 : 동축 케이블(케이블 TV망) 사용
  - DSL 모뎀 : 전화선 사용 (ADSL, VDSL)
  - 광모뎀(ONT) : 광케이블 사용 (FTTH)

**공유기**

- 하나의 인터넷 회선을 여러 단말이 함께 사용할 수 있도록 해주는 장비
- 내부적으로 여러 기능의 회로가 하나로 합쳐져 있음
  - **라우터** : 내부 네트워크와 외부(인터넷)를 연결함
  - **스위치** : 여러 대의 유선 단말을 연결함 (LAN 포트)
  - **무선 AP** : 무선(Wi-Fi) 단말을 연결함
- 주요 기능
  - **NAT(Network Address Translation)** : 하나의 공인 IP를 여러 단말의 사설 IP(예: `192.168.0.x`)로 나눠 사용할 수 있도록 주소를 변환함
  - **DHCP** : 연결된 단말에 사설 IP 주소를 자동으로 할당함
